# BankBuddy UI

React frontend for BankBuddy, built with [Vite](https://vite.dev).

Requires Node.js 20.19+ (see `.nvmrc`; run `nvm use` in this folder).

## Scripts

- `npm start` (or `npm run dev`) – start the dev server at [http://localhost:3000](http://localhost:3000) with hot reload.
- `npm run build` – create a production build in `dist/`.
- `npm run preview` – serve the production build locally to check it.

The UI expects the Flask backend at `http://127.0.0.1:5000`.
